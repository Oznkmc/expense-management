# 💰 Expense Management App

React Native (Expo), TypeScript ve Firebase kullanılarak geliştirilmiş, kullanıcıların gelir–gider takibi yapmasını ve bütçesini yönetmesini sağlayan cross-platform mobil uygulama.

---

## 🚀 Proje Hakkında

Bu uygulama, bireysel kullanıcıların finansal durumlarını kontrol edebilmesi için geliştirilmiştir.

Kullanıcılar:

- Günlük gelir ve giderlerini kaydedebilir
- Borç / alacak takibi yapabilir
- Finansal hedefler belirleyebilir
- Kategori bazlı bütçe planlaması yapabilir
- Harcama analizlerini grafikler üzerinden görüntüleyebilir

Uygulama, kullanıcı bazlı güvenli veri yönetimi ve gerçek zamanlı senkronizasyon sunar.

---

## 🏗️ Kullanılan Teknolojiler

- TypeScript
- React Native (Expo)
- Expo Router
- Firebase Authentication
- Firebase Firestore (Real-time Database)
- React Hooks (useState, useEffect)
- Async/Await (Asenkron veri yönetimi)

---

## 📊 Temel Özellikler

### 💵 Gelir & Gider Takibi
- Kullanıcı bazlı veri kaydı
- CRUD işlemleri (Create, Read, Update, Delete)
- Gerçek zamanlı toplam hesaplama

### 📂 Kategori Bazlı Bütçeleme
- Harcamaları kategoriye göre filtreleme
- Dinamik toplam ve analiz sistemi
- Grafik destekli raporlama

### 📌 Borç / Alacak Yönetimi
- Borç ve alacak kayıt sistemi
- Durum takibi

### ⚡ Kullanıcı Deneyimi
- Swipe-to-delete özelliği
- Hızlı işlem ekleme
- Dinamik liste güncelleme
- Basit ve modern arayüz tasarımı

---

## 🔐 Mimari Yapı

- TypeScript ile type-safe component yapısı
- Firebase Authentication ile güvenli kullanıcı doğrulama
- Firestore ile kullanıcı bazlı gerçek zamanlı veri senkronizasyonu
- Asenkron veri yönetimi (async/await)
